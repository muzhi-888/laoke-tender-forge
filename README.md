# laoke-tender-forge · 招投标文档生成器

> 局内人·老K · 专注实体老板 AI 落地实战

通用招投标标书智能生成与合规自检工具。覆盖商务标 / 技术标 / 价格标三段式结构，自动生成偏离表与响应表，跑 11 条废标红线合规自检。适用于政企采购、工程、服务类招标的投标负责人、商务经理与标书代写者。

## 这个工具能做什么

- 解读评分办法，把打分项拆成可落地的应答清单（客观分备证、主观分打磨）。
- 按商务标 / 技术标 / 价格标生成结构完整的标书 Markdown 草稿。
- 自动生成《偏离表 / 响应表》，逐条标注正偏离 / 无偏离 / 负偏离。
- 生成投标函、授权委托书、报价一览表、资质清单等标准模块。
- 跑合规自检：废标条款、资质缺口、签字盖章遗漏一键排查。
- 内置合规护栏，硬拒围标串标陪标虚假资质等违规请求。

## 目录结构

```
SKILL.md                  技能主文件（含完整使用指南）
_meta.json               元数据
references/              5 份领域知识（术语、评分办法、结构模板、偏离表、废标红线）
scripts/build_response_matrix.py   偏离表自动生成与合规自检（纯标准库，本地运行）
hooks/guardrail.md       合规护栏
icon.png                 技能图标
```

## 快速开始

```bash
# 跑内置演示，生成偏离表样例
python scripts/build_response_matrix.py

# 用你自己的对照数据（TSV：条款号|招标要求|投标响应）
python scripts/build_response_matrix.py your_input.tsv out.md
```
