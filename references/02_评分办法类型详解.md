# 评分办法类型详解与应答策略

评分办法决定"分从哪来"，是标书用力方向的指挥棒。本文件拆解三类主流办法及对应策略。

## 一、最低价评标法

**机制**：投标人满足基本要求后，报价最低者中标。
**适用**：标准统一、技术简单、差异小的货物/服务（如通用办公用品批量采购）。
**应答策略**：
- 价格标是唯一胜负手，商务技术"不废标即可"。
- 精算成本底线，压价但不低于成本（防"不合理低价"质疑）。
- 技术标只做"满足性响应"，不堆料浪费精力。
**风险**：恶性低价竞争，中标后履约压力大；注意招标是否设"成本价澄清"环节。

## 二、综合评分法（最常见）

**机制**：商务、技术、价格按权重打分求和，总分高者中标。
**权重示例**：商务 30% + 技术 50% + 价格 20%（工程/服务类技术权重常更高）；货物类价格权重可能更高。

**应答策略核心是"分项拆解"：**
1. 抽出每个评分大项、子项、分值。
2. 区分客观分与主观分：
   - 客观分：看硬条件（资质、业绩、证书、报表），你有什么就是多少分，改不了，只能"备齐证据"。
   - 主观分：看表述（项目理解、实施方案、售后），可争取，重点写。
3. 把主观分拆成"应答要点 + 建议附证"，逐段落到标书。
4. 输出《评分项→标书位置→责任模块》映射表，确保不漏项。

**价格分常见算法：**
- 公式 A：`报价得分 = (评标基准价 / 投标报价) × 价格权重分`
- 公式 B：`基准价 = 有效报价去掉最高最低后的平均`（或平均下浮一定比例）
- 部分项目设"低于基准价也扣分"条款，防恶意低价。

**主观分加分要点：**
- 每段开头"一句话结论 + 展开"，让专家秒抓重点。
- 给具体数字（人数、天数、到场时间、备件数量）。
- 做"对照表"让专家一眼看到你满足。
- 正偏离写清"优于多少、凭什么"。

## 三、性价比法

**机制**：分数 = 技术得分 / 报价（或类似），兼顾质量与价格。
**适用**：技术差异大、需鼓励优质优价的项目。
**应答策略**：保住技术分前提下理性压价，但报价不能过低被质疑成本。

## 四、其他变体

- **基准价浮动法**：在综合评分基础上，对报价偏离基准价设阶梯扣分。
- **合格制 + 随机抽签**：资格后审合格即入围，中标靠抽签（常见于小额工程）。应答重点在"资格过关"，技术标从简。
- **两阶段招标**：先评技术案（隐去身份），再开报价。技术标权重极高，需打磨方案。

## 五、实操：拿到评分办法先做四件事

1. 列出所有大项及分值，算权重。
2. 标"客观/主观"，客观分备证、主观分打磨。
3. 找实质性条款（★）单独列出，确认零负偏离。
4. 找价格分算法，确认报价区间（≤限价，且算过基准价敏感度）。

> 经验：很多投标人败在"主观分没写透"。客观分大家差不多，差距全在主观分的表述质量——把真实能力讲清楚，就是最稳的加分。
