# 废标红线与合规清单

废标 = 投标被判定无效，前期投入归零。本文件汇总高频废标原因与合规自检清单，供定稿前逐条打勾。

## 一、高频废标原因排名（按发生频率）

1. 投标保证金未缴/金额不足/到账晚。
2. 文件未按要求密封或电子标未 CA 签章/漏签。
3. 报价超过招标控制价（限价）。
4. 工期/服务期不满足实质性要求。
5. 资格证明缺失或过期（资质证书过期最常见）。
6. 联合体未提交共同投标协议（如要求联合体）。
7. 投标有效期不足。
8. 关键技术参数（★条款）负偏离。
9. 串通投标痕迹（不同投标人文件异常一致、IP/MAC 相同）。
10. 未按格式填，关键页漏签。

## 二、11 条不废标底线（生成后必跑）

1. 投标函项目名/编号/报价与报价表一致。
2. 报价大小写一致、无计算错误。
3. 资质证书在有效期内。
4. 实质性条款（★）全部满足，无负偏离。
5. 投标有效期、工期/服务期响应招标要求。
6. 投标保证金已缴、凭证齐全。
7. 授权书被授权人身份与递交人一致。
8. 所有签字盖章位置已覆盖（含电子签章）。
9. 无虚假业绩/伪造证书（疑点提示人工复核）。
10. 无围标串标陪标相关表述。
11. 文件格式（PDF/Word/加密）符合招标递交要求。

## 三、串通投标认定（硬拒，勿碰）

以下情形依《招标投标法》《政府采购法》及实施条例可被认定串标，涉刑：
- 投标人之间协商报价、技术方案等实质性内容。
- 投标人之间约定中标人、约定部分人放弃投标。
- 不同投标人文件由同一单位/个人编制（MAC/IP/内容高度一致）。
- 不同投标人保证金从同一账户转出。
- 投标人之间为谋取中标排斥竞争对手的其他联合行动。
- 招标人与投标人串通（泄露标底、明示偏好等）。

> 本 Skill 对任何形式的围标、串标、陪标、泄露标底、贿赂评委请求一律拒绝，并提示法律风险。合法竞争、凭真实实力取胜才是正道。

## 四、电子标特有废点

- CA 锁失效/驱动不对 → 无法签章。
- 价格标未加密或开标未解密 → 视为撤标。
- 文件格式非招标文件指定制作工具导出 → 无法上传/解析。
- 截止时间后上传 → 系统自动拒收。

## 五、定稿前最终 Checklist（负责人逐条打勾）

- [ ] 投标函三处一致（项目名/编号/报价大小写）
- [ ] 报价汇总 = 分项之和 = 大小写一致
- [ ] 所有 ★ 实质性条款无负偏离
- [ ] 资质证书在有效期，编号等级无误
- [ ] 业绩合同关键页齐全、对应评分项
- [ ] 偏离表逐条填，无"详见技术"糊弄
- [ ] 电子签章每页覆盖，CA 锁可用
- [ ] 投标保证金凭证在，金额到账无误
- [ ] 授权人与递交人一致，身份证随身
- [ ] 密封/加密符合递交要求
- [ ] 提前 2 小时完成上传/递交，留缓冲

```

项目：____
生成时间：____
结果：通过 / 存在 N 项需人工复核

[红线1] 投标函一致性 ...... 通过
[红线2] 报价计算 ...... 通过
[红线3] 资质有效期 ...... 通过
[红线4] 实质性条款零负偏离 ...... 通过
[红线5] 工期/服务期响应 ...... 通过
[红线6] 投标保证金 ...... 待确认（请附凭证）
[红线7] 授权人一致 ...... 通过
[红线8] 签章覆盖 ...... 待确认（电子标请验CA）
[红线9] 无虚假材料 ...... 通过（AI未检出，需人工复核）
[红线10] 无违规表述 ...... 通过
[红线11] 文件格式 ...... 待确认（按平台要求）
======================
```

> 标"待确认"的项不自动判定通过，必须人工复核打勾后才能定稿。脚本不替代负责人责任。
