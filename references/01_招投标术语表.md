# 招投标核心术语表

本表为标书制作必备术语速查，避免沟通与撰写时用词错乱。

| 术语 | 含义 | 实务提醒 |
|------|------|----------|
| 招标人 | 提出采购/工程需求、发标的一方（甲方） | 多为机关、事业单位、国企或大型企业 |
| 投标人 | 响应招标、递交投标文件的一方（乙方） | 需具备招标文件要求的资格条件 |
| 招标代理 | 受招标人委托组织招标的中介机构 | 答疑、澄清、开标多由代理执行 |
| 招标文件 | 含投标人须知、技术规格、评分办法、合同草案 | 一切应答的"圣经"，以它为准 |
| 投标文件 | 投标人递交的应答文件（即标书） | 组成、格式、密封以招标要求为准 |
| 投标人须知前附表 | 把通用须知里本项目的关键参数单独列出 | 高频废标条款来源，必读 |
| 实质性条款 | 标"★"或写"不满足则投标无效"的硬要求 | 负偏离直接废标，零容忍 |
| 评分办法 | 商务/技术/价格如何打分的规则 | 决定用力方向 |
| 招标控制价 | 招标人设的最高限价 | 超过即废标 |
| 评标基准价 | 综合评分法里算价格分的参照价 | 报价越接近越高分（部分设下限） |
| 投标保证金 | 投标时缴的担保，防撤标/违规 | 金额、到账时间、凭证缺一不可 |
| 履约担保 | 中标后提交的履约保证（保函/现金） | 不交视为放弃中标 |
| 偏离 | 投标响应与招标要求不一致 | 分正/无/负偏离 |
| 正偏离 | 优于招标要求 | 加分点，须真实 |
| 负偏离 | 不满足招标要求 | 触实质性条款即废标 |
| CA 证书 | 电子招投标的数字身份（U 盾） | 签章、加密、解密都靠它 |
| 澄清 | 评标中专家要求解释（不改实质） | 只解释不降价不加承诺 |
| 联合体 | 多家单位共同投标 | 需共同投标协议，责任连带 |
| 串标/围标 | 投标人串通操纵结果 | 违法，入刑，本 Skill 硬拒 |
| 废标 | 投标被判定无效 | 多为资质/保证金/签章/限价问题 |
| 流标 | 有效投标不足三家等导致招标失败 | 与废标不同，指整个项目 |
| 唱标 | 开标时公开宣读报价等 | 公开招标开标环节 |
| 定标 | 确定中标人 | 之后发中标通知书 |

## 常见资质名词

- 建筑/工程类：施工总承包资质（特级~三级）、专业承包资质、安全生产许可证、项目经理注册证书（一/二级建造师）。
- 货物类：制造商授权书、产品检测报告、3C 认证、节能产品认证、ISO 体系证书。
- 服务类：相关行业许可、人员职业资格证书、CMMI/ITSS 等。
- 通用：营业执照、开户许可证、ISO9001 质量体系、ISO14001 环境体系、ISO27001 信息安全。

## 金额写法规范

- 报价须同时写"大写"与"小写"，小写用阿拉伯数字加"¥"或"人民币"，大写用"零壹贰叁肆伍陆柒捌玖拾佰仟万"且到"元/角/分"。
- 示例：¥1,280,000.00 对应"人民币壹佰贰拾捌万元整"。
- 大小写不一致时通常以大写为准，但混乱会被质疑，定稿务必一致。
